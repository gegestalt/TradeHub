HOW THE APPLICATION WORKS
--------------------------
1. Every person registers once → gets a permanent USER TOKEN.
2. To play in a competition, the user creates or joins it → gets a PLAYER TOKEN
   specific to that competition. The player token is what you use for trading.
3. User token   = who you are (permanent, works across all competitions)
4. Player token = your seat at a specific table (one per competition)
5. Spectators join with spectator:true — they get NO cash balance and cannot
   trade. They are excluded from the leaderboard. Their player token has no
   practical use in the game.
6. The database is a file (tradehub.db). All data survives server restarts.
   Stopping and restarting the server does NOT wipe your competitions or players.

BALANCE & BUDGET PROTECTION (built in)
---------------------------------------
- Buying: server checks cash_balance >= (price * quantity * (1 + fee_pct)).
  If not enough cash → order is rejected with 400.
- Selling: server checks you own at least as many shares as you want to sell.
  If not enough position → order is rejected with 400.
- Leverage: server checks order notional does not exceed
  cash_balance * max_leverage. Default max_leverage is 1 (no leverage).
- Per-player lock prevents two simultaneous orders from both spending the
  same balance (race condition protection).

BEFORE YOU START
----------------
1. Start the backend:
   cd backend
   uv run uvicorn main:app --reload --reload-dir .

2. In Postman create an Environment called "TradeHub" with these variables
   (leave values blank — fill them in as you go through the steps):

   base                 = http://localhost:8000
   ALICE_TOKEN
   BOB_TOKEN
   CHARLIE_TOKEN
   CODE
   ALICE_PLAYER_TOKEN
   ALICE_PLAYER_ID
   BOB_PLAYER_TOKEN
   BOB_PLAYER_ID
   CHARLIE_PLAYER_TOKEN
   CHARLIE_PLAYER_ID
   LIMIT_ORDER_ID

3. Select the "TradeHub" environment in the top-right dropdown.
